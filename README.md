# 智启新质 · AI × New Quality Productive Forces

> **人工智能驱动新质生产力可视化数字展馆**
>
> 人工智能，正在重新定义生产力。从数据感知、智能决策到产业重构，探索人工智能如何成为新质生产力的重要驱动力。

这是一个大学课程作业项目，定位为 **沉浸式数字展馆 + 数据可视化网站 + AI 交互实验平台**。网站以完整的叙事逻辑串联「认知 → 机制 → 产业 → 效率 → 数据 → 未来 → 实验 → 沙盘 → 生态 → 价值 → 区域」11 个展区，通过动态图表、场景化 SVG 与可交互实验，展示 **AI 如何推动新质生产力**。

## 核心特性

- **沉浸式首页**：动态「AI 新质生产力引擎」，以 AI Core 为中心，连接数据、算法、算力、场景、人才五大技术要素与制造、医疗、能源、交通、农业、科研六大产业；节点浮动、数据流动、悬停高亮。
- **认知展区（01）**：传统生产模式 vs AI 驱动生产模式对比，点击 AI 节点触发转换动画；高科技 / 高效能 / 高质量三大特征卡片与微型动态图表。
- **机制展区（02）**：数据 → 感知 → 分析 → 预测 → 决策 → 执行 → 反馈 → 优化的智能生产闭环，支持「播放 AI 决策流程」逐个点亮节点；感知 / 认知 / 行动三大生产力动态 SVG。
- **产业展区（03）**：可交互产业地图（8 大领域，点击查看应用与价值面板）+ Industry Explorer 五个产业案例的动态场景（制造、交通、医疗、农业、能源）。
- **效率展区（04）**：KPI 看板、柱状 / 折线 / 雷达图、**AI 生产力模拟器**（4 个滑块实时计算指数）、Human × AI 协同、Before / After 拖动对比、AI 生产力网络关系图（悬停高亮整条价值路径）。
- **数据驾驶舱（05）**：KPI 卡片、产业应用环形图、AI 能力雷达、效率提升条形图、应用趋势折线、产业智能化热力图。
- **未来展区（06）**：2020 → 2025 → 2030 → Future 时间轴与「未来智能工厂」动态图。
- **AI 交互实验室（07）**：四个可亲手操作的实验——
  1. 机器视觉检测（框选缺陷 + 置信度）
  2. 智能调度（甘特图对比传统 / AI 排程）
  3. 预测性维护（自动标记异常振动）
  4. AI 决策（输入参数，输出产线分配方案与饼图）
- **AI 新质生产力沙盘（08）**：拖动 **AI 渗透率 / 算力投入 / 数据利用率 / 自动化程度 / 人机协同程度** 五个参数，左侧传统工厂按「设备连接 → 数据流动 → AI 中枢启动 → 机器人协同 → 调度优化 → 故障预警 → 产线重组」七个阶段实时演化；右侧五项 KPI（生产效率 ↑、单位成本 ↓、产品缺陷率 ↓、资源利用率 ↑、创新周期 ↓）同步联动，新质生产力指数由 **42 升至 87**；演化完成后中央给出结论——AI 不是简单替代劳动，而是在重组数据、技术、劳动者与生产资料之间的关系。支持「一键演化」播放全过程。
- **生态图谱（09）**：通过桑基图、关系网络和矩形树图展示 AI 产业生态中的技术、资源、主体与应用关系。
- **价值转化（10）**：使用漏斗图和联动仪表盘解释数据、技术能力如何逐层转化为生产效率、创新能力与社会价值。
- **区域图景（11）**：以区域融合活跃度与社会价值结构图呈现 AI 赋能新质生产力的空间差异和综合作用；相关指数均明确标注为概念模型。
- **体验 AI 之旅（独立页面）**：通过 9 个章节介绍 AI 发展、神经元、前向传播和 MNIST 识别流程，并提供使用预训练权重的浏览器端手写数字识别。

## 快速开始

### 环境要求

- **Node.js ≥ 18**（推荐 20 / 22 LTS）
- npm（或 pnpm / yarn）

### 安装与运行

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 3. 构建生产版本（输出到 dist/）
npm run build

# 4. 本地预览生产构建
npm run preview
```

## 数据来源与真实性声明

本项目为教学可视化作品，数据使用遵循以下原则：

- **统计数据均标注来源**：首页指标、效率展区、数据驾驶舱和未来展区中标注为统计或机构预测的数据，来自国家统计局、中国信通院、CNNIC、国家网信办、国家数据局、世界经济论坛（WEF）、麦肯锡全球研究院（MGI）、普华永道（PwC）、斯坦福 HAI、IDC、高盛、IFR、WIPO 等公开资料；
- **每张主要图表都有「这一图说明什么」结论层**：在数据来源之上给出一句可检验的观点（如机器人密度图下写「AI 与机器人技术正在推动制造业由劳动密集型向智能密集型转变」），首页则以「核心论点」明示全文主线，形成 **数据 → 结论 → 新质生产力** 的闭环；
- **概念模型明确标注**：生产模式雷达图、产业智能化热力图、生态关系、价值链和区域融合指数等内容为编者综合公开资料构建的解释性模型，均按「非统计口径」展示；
- **交互实验为前端模拟**：AI 实验室中的「检测、调度、维护、决策」、「AI 生产力模拟器」与「AI 新质生产力沙盘」均为前端交互模拟，不调用真实 AI 模型，不构成任何真实产业预测或统计结论；
- 手写数字识别实验使用真实的 MNIST 预训练权重在浏览器本地推理。

数据层统一使用三类标记：`stat` 表示带来源的统计数据，`concept` 表示解释性概念模型，`simulation` 表示教学模拟。三类内容不可相互替代。

## 工程说明

- 应用为纯前端单页网站，不包含后端服务、数据库、用户系统或真实工业设备接口；
- 主展馆与「体验 AI 之旅」通过轻量 Hash 路由切换；
- AI 实验室、生产力模拟器和沙盘中的结果由前端规则与假设参数生成，主要用于解释 AI 工作流程；
- 生产构建会依次执行 TypeScript 类型检查和 Vite 打包：`tsc --noEmit && vite build --minify terser`；
- 当前未配置自动化单元测试或端到端测试，页面效果仍需结合浏览器交互进行验收。
